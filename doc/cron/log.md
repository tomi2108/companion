# maro cron log

Show logs for the last Job (pod) run by a CronJob, interactively.

## Usage

```bash
maro cron log
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None     | None  | None    | None |

## Notes

- Requires connection and access to the OpenShift API server.
- Only CronJobs and Jobs in the current/selected namespace are listed.
- Aliases: none
