# maro cron create

Create an OpenShift CronJob from a deployment.

## Usage

```bash
maro cron create
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None     | None  | None | None        |

## Notes

- Requires `paths.namespaces` to be set in your configuration.
- Creates the CronJob on the specified OpenShift project using deployment details.
