# maro config setup

Run the interactive configuration setup for maro.

## Usage

```bash
maro config setup
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None     | None  | None | None        |

## Notes

- Runs an interactive setup process to configure core settings for maro.
- This should be used when initializing a new environment or updating configuration.
