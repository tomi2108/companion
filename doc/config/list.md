# maro config list

List all configuration keys, types, and descriptions for the application.

## Usage

```bash
maro config list
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None     | None  | None | None        |

## Notes

- This command displays all available configuration keys, their types, and descriptions for each config section.
