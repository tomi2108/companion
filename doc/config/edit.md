# maro config edit

Edit the main application config file in your default editor.

## Usage

```bash
maro config edit
```

## Arguments

| Argument | Alias          | Type | Description |
| -------- | -------------- | ---- | ----------- |
| None     | o, open, e     | None | None        |

## Notes

- Opens the project's primary JSON config file for direct editing in your configured `$EDITOR`.
