# maro pod remote-session

Start an interactive remote shell session in an OpenShift pod.

## Usage

```bash
maro pod remote-session
```

## Arguments

| Argument | Alias       | Type | Description |
| -------- | ----------- | ---- | ----------- |
| None     | rsh, remote | None | None        |

## Notes

- Connects you to a bash/zsh session in the selected running pod/container.
