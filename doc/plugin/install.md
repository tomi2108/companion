# maro plugin install

Install a maro plugin from a git URL.

## Usage

```bash
maro plugin install
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None     | None  | None | None        |

## Notes

- Installs a maro plugin from the provided git URL.
- Plugin directory location and disabled list are pulled from configuration.
