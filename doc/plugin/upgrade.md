# maro plugin upgrade

Upgrade a maro plugin to the latest version from its source repository.

## Usage

```bash
maro plugin upgrade
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None     | None  | None | None        |

## Notes

- Pulls changes from the master branch of the plugin's repository and rebuilds it.
