# maro mr open

Open a merge request in the browser for the current repository.

## Usage

```bash
maro mr open
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None     | None  | None | None        |

## Notes

- Requires access to the repository in the current working directory.
- Opens the merge request web page in your default browser.
