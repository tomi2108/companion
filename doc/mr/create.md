# maro mr create

Create a merge request in the current repository, and optionally merge it directly.

## Usage

```bash
maro mr create
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None     | None  | None | None        |

## Notes

- Optionally merges the merge request upon creation.
- Requires access to the repository in the current working directory.
