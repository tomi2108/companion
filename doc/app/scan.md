# maro app scan

Run a Sonar scan on the application.

## Usage

```bash
maro app scan
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None | None | None | None |

## Notes

- Requires properly configured paths for frontend and backend repositories.
- SonarQube/SonarCloud integration and relevant config must be present.
