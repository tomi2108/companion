# maro app expose

Expose an app in 3scale.

## Usage

```bash
maro app expose
```

## Arguments

| Argument | Alias | Type | Description |
| -------- | ----- | ---- | ----------- |
| None | None | None | None |

## Notes

- This command interacts with 3scale and OpenShift deployments.
- It requires 3scale and OpenShift to be properly configured in your environment.
- Alias: `maro app e`
