# maro app rename

Rename application repositories in bulk.

## Usage

```bash
maro app rename [options]
```

## Arguments

| Argument | Alias | Type | Description |
| -------  | ----- | ---- | ----------- |
| --all    | -a    | boolean | Run for all repositories |
| --frontend | -f  | boolean | Run for all frontend repositories |
| --backend | -b  | boolean | Run for all backend repositories |

## Notes

- Requires properly configured paths for frontend and/or backend repositories.
